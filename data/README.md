# Данные

В репозиторий попадают **только синтетические кейсы** из `data/synthetic/`.

Нельзя загружать в GitHub:
- работы студентов прошлых лет;
- файлы с персональными данными;
- экспертные оценки с именами.

Работы прошлых лет используются только после проверки разрешений и условий обработки, включая передачу внешним AI-сервисам.
